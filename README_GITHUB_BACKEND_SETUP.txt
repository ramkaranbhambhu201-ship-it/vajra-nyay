IMPORTANT: GitHub Pages is static and cannot run server.js.
For live Pocket Rights API:
1) Upload the `backend` folder to this repository.
2) Deploy the backend folder as a Node Web Service (Render is supported by backend/render.yaml).
3) Set GROQ_API_KEY as a backend secret only; never put it in GitHub/index.html.
4) In the app's Home -> Government/Police API Connection panel, save the deployed backend URL.
5) Refresh the GitHub Pages app and test Pocket Rights.
