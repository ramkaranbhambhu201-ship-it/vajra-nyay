VAJRA NYAY — GITHUB READY

इस पैकेज में दो हिस्से पहले से तैयार हैं:
1) index.html = GitHub Pages frontend
2) backend/ = Node/Express backend (Render जैसी service पर चलाने के लिए)

GitHub पर आसान तरीका:
- इस ZIP को Extract करें।
- GitHub repository में ROOT का index.html upload करें।
- साथ में backend folder भी upload करें।
- GitHub Pages index.html खोलेगा।
- backend folder को Render Web Service के Root Directory के रूप में चुनें।
  Build: npm install
  Start: npm start
- Render URL मिलने के बाद GitHub वाले app में नीचे Backend Connection box में URL एक बार Save करें।

महत्वपूर्ण:
GitHub Pages स्वयं Node backend नहीं चलाता। इसलिए backend source GitHub में रह सकता है, लेकिन उसे Render जैसी server service पर deploy करना होगा।
Government submission अभी OFF है; official permission/API मिलने के बाद ही जोड़ा जाएगा।
Map पर रिश्वत से संबंधित रिकॉर्ड को complaint/allegation के रूप में दिखाया जाना चाहिए; उसे स्वतः सिद्ध तथ्य नहीं माना गया है।
